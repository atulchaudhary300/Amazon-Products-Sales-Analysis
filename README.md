# Amazon Products Sales Analysis Dashboard

## Project Overview
This project analyzes Amazon product sales data using Power BI.
The dashboard provides insights into sales performance, product categories,
weekly and monthly sales trends, and customer reviews.

## Dashboard KPIs
- YTD Sales: $1.24M
- QTD Sales: $486K
- YTD Products Sold: 18.22K
- YTD Reviews: 13.16M

## Key Analysis
- Sales by Month
- Sales by Week
- Sales by Product Category
- Top 5 Products by YTD Sales
- Top 5 Products by YTD Reviews
- Product Category Performance

## Tools & Technologies
- Power BI
- Power Query
- DAX
- Data Cleaning
- Data Visualization
- Data Analysis
